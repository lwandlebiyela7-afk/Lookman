# Lwandle’s Shadow Clash (2D prototype)

A fast 2D anime-inspired fighting game with 16 selectable original fighter variants, mobile controls, and an original Japanese-anime-inspired instrumental loop generated in the browser using Web Audio. The music is not a Naruto soundtrack or a copied commercial recording. Tap the music button on the title screen to enable or mute it (browsers require a tap before audio can play).

## Publish on GitHub Pages
Upload `index.html`, `manifest.json`, `sw.js`, the `icons` folder and this README to the repository root. In GitHub, open **Settings → Pages**, choose deploy from branch `main` and folder `/ (root)`, then open the HTTPS Pages URL on Android.

## Install on Android
Open the HTTPS Pages URL in Chrome → ⋮ → **Install app** or **Add to Home screen**. This installs a web app, not a native APK.

## Controls
Phone: touch buttons. Keyboard: A/D or arrows move, W/Up jump, J hit, K heavy, L jutsu, Shift dash, I ultimate, S/Down guard.

## Audio note
The loop is original, synthesized audio inspired by Japanese anime battle music. Naruto's actual soundtrack is copyrighted, so this project does not bundle it.
